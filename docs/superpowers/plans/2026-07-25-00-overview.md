### 實作過程中確認的環境事實

- `dotnet new sln` 在 .NET 10 SDK 產生 **`MyCollection.slnx`**（XML 格式），不是 `.sln`。
- Infrastructure 專案加了 `FrameworkReference Microsoft.AspNetCore.App` 後，**不可**再顯式參考 `Microsoft.Extensions.*` 套件，否則觸發 **NU1510** 套件剪除警告，在 `TreatWarningsAsErrors=true` 下即為建置失敗。正解是移除顯式 `PackageReference`。
- `AddOpenApi()` / `MapOpenApi()` **不在** Web SDK 隱含提供，需顯式加 `Microsoft.AspNetCore.OpenApi`。該套件遞移帶入的 `Microsoft.OpenApi 2.0.0` 有已知高風險弱點（GHSA-v5pm-xwqc-g5wc），觸發 **NU1903** 使還原失敗。正解是在 Api 專案顯式參考 `Microsoft.OpenApi 2.11.0` 覆寫版本，**不是** `NoWarn`。
- 移除套件的語法是 `dotnet package remove <name> --project <path>`；舊的 `dotnet remove <project> package <name>` 在此 SDK 已失效。
- **複合唯一索引不能用 `Sparse = true` 排除文件**。MongoDB 的 sparse 複合索引只要文件含有**任一**索引欄位就會納入索引；`ownerId` 恆存在，所以 `(ownerId, externalRef.provider, externalRef.externalId)` 加 sparse 之後，每筆手動品項都以 `(ownerId, null, null)` 進索引，同一使用者的第二筆手動品項就撞 `E11000`。已實測驗證。正解是 `PartialFilterExpression = Builders<T>.Filter.Exists("externalRef.provider")`。（單欄位 sparse 索引如 `ix_users_refreshTokenHash` 不受影響，行為正常。）
- **分頁排序必須是全序**。BSON `DateTime` 只有毫秒精度，`updatedAt` 極易並列；排序鍵並列時 MongoDB 不保證跨查詢的順序穩定，使用者翻頁會看到重複或遺漏。所有分頁查詢都要加 `_id` 作為決定性次要排序鍵。
- **Mongo driver 的 `.Project(...)` 泛型參數不可省略**。`Builders<T>.Projection.Include(...)` 回傳的 `ProjectionDefinition<T>` 實際上是 `ProjectionDefinition<T, T>` 的子型別，型別推斷會把 `TNewProjection` 解析成 `T`，結果拿到 `List<T>` 而非 `List<BsonDocument>`。要投影成 `BsonDocument` 必須明寫 `.Project<BsonDocument>(projection)`。
- **`dotnet add package SixLabors.ImageSharp` 不指定版本會裝到 4.0.0**。本專案鎖 3.x，須加 `--version`。另外套件版本一律寫死（如 `3.1.12`），不用浮動版本 `3.1.*`，否則建置不可重現。
- **`UtcOnlyDateTimeSerializer` 連「沒設定過的 DateTime」也會拒絕**：未指定的 `DateTime` 是 `MinValue`，`Kind` 為 `Unspecified`，序列化時直接擲例外。因此**任何要寫入 Mongo 的實體，其所有非可空 `DateTime` 欄位都必須明確賦值**（`CreatedAt` / `UpdatedAt` / `ExternalRef.LastSyncedAt` 等）。這是刻意的：與其讓 `0001-01-01` 悄悄寫進資料庫，不如當場爆掉。建構實體的測試與 Handler 都要留意。

### 對 spec 的兩處明確擴充

1. **`ConflictException` → HTTP 409**。spec §8 表格未列，但 email 重複、share slug 重複需要它（unique index 撞擊的競態）。
2. **Domain 依賴 `MongoDB.Bson`**。spec §4 寫「零外部相依」，但 §5.2 要求 `attributes` 為 `BsonDocument`。折衷：Domain 只引用 `MongoDB.Bson`（純序列化型別，無 I/O），**不引用** `MongoDB.Driver`。
