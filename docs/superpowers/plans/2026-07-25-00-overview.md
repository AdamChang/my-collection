## 跨計畫的固定約定

這些決定在 Plan 1 定案，後續計畫直接沿用，**不得重新命名**：

### 目錄結構

```
MyCollection.sln
src/MyCollection.Domain/          Entities/ ValueObjects/ Exceptions/
src/MyCollection.Application/     Common/ Auth/ Categories/ Items/ Media/ Showcase/ Sharing/ Ingestion/
src/MyCollection.Infrastructure/  Mongo/ Storage/ Security/ Imaging/ Providers/
src/MyCollection.Api/             Endpoints/ Program.cs
tests/MyCollection.Tests/         Unit/ Integration/ Fixtures/
web/                              Angular 20
docker-compose.yml
```

### 命名對照表（型別 / 方法 / 設定鍵）

| 類別 | 名稱 |
|---|---|
| Mongo 連線包裝 | `MongoContext`，屬性 `Users` `Categories` `Items` `ExternalAccounts` `SyncJobs` `ShareLinks` |
| 索引建立 | `MongoIndexInitializer.EnsureIndexesAsync(MongoContext, CancellationToken)` |
| 目前使用者 | `IUserContext { ObjectId UserId; bool IsAuthenticated; }` |
| 時間 | 一律注入 BCL `TimeProvider`，取 `GetUtcNow().UtcDateTime`，不自訂 `IClock` |
| 設定區段 | `Mongo:*` `Jwt:*` `Storage:*` `Steam:*` |
| 測試 fixture | `MongoFixture`（Testcontainers），collection 名稱常數 `MongoCollection.Name` |

### 對 spec 的兩處明確擴充

1. **`ConflictException` → HTTP 409**。spec §8 表格未列，但 email 重複、share slug 重複需要它（unique index 撞擊的競態）。
2. **Domain 依賴 `MongoDB.Bson`**。spec §4 寫「零外部相依」，但 §5.2 要求 `attributes` 為 `BsonDocument`。折衷：Domain 只引用 `MongoDB.Bson`（純序列化型別，無 I/O），**不引用** `MongoDB.Driver`。

### 執行方式
