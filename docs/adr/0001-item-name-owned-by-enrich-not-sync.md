# 品項名稱由補完擁有，同步只在建立時寫入

Steam 的 Web API 只回得到英文品名，繁體中文品名只有商店端點提供，而後者屬於補完路徑。若同步繼續在每次執行時覆寫品名，補完寫好的繁中名稱會在下一次同步被默默改回英文——沒有錯誤、沒有失敗的作業，資料就悄悄退回去了。因此同步對品名改用 `$setOnInsert`，補完的寫入契約放寬為可寫品名。

## Consequences

- Steam 端真正的更名（例如搶先體驗轉正式版改名）不再自動傳播進來，使用者需要按單筆重新抓取。
- 附帶修掉一個既有問題：使用者手動改過的品名以前會被每次同步蓋掉，現在得以保留。
- 這個決定只有一道護欄——`MongoItemSyncWriter` 的「同步不覆寫既有名稱」測試。它若被移除，回歸不會有任何外顯症狀。
