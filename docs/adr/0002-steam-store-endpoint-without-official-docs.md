# 繁體中文中繼資料取自無官方文件的 Steam 商店端點

Steam 的官方 Web API 沒有語言參數，IGDB 的在地化資料只有標題沒有簡介，兩者都無法達成「品名、簡介、類型都是繁體中文」。唯一能同時提供三者的是商店的 app 詳細資料端點，但它沒有官方文件、沒有 SLA，Valve 隨時可以改。我們接受這個風險，因為替代方案是這個功能做不出來。

## Considered Options

- **IGDB 的在地化資料**：官方端點、可批次，但只有標題沒有簡介，且會與「品名由本地化補完無條件覆蓋」的擁有權模型衝突——品名永遠有值，IGDB 的在地化標題一行也套不進去。
- **不做繁中**：使用者的實際問題（認不出遊戲、搜尋不到）就不會被解決。

## Consequences

- 該端點不支援批次，一次只能查一個 app；速率上限約每五分鐘兩百次，因此補完必然是慢的背景作業。
- 所有已知行為（品名在沒有繁中版時退回原文、類型一律本地化、不可批次）都來自實測而非文件。主接縫測試中「有繁中版」與「退回原文」兩案是行為變更的偵測器。
- 商店回應中的開發商、發行商仍是英文原名，發售日期是無法穩定解析的本地化字串——這些欄位維持由 IGDB 提供。
